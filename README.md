# CEH v13 Lab Write-ups

A collection of my **CEH v13 hands-on lab write-ups**, documenting the process, techniques, tools, findings, and lessons learned while practicing ethical hacking and cybersecurity.

This repository is primarily a **learning record and technical reference** for my CEH v13 training.

## What This Repository Contains

Each write-up documents a completed lab or practical exercise, including:

* Lab objective
* Target/environment information
* Reconnaissance
* Enumeration
* Vulnerability identification
* Exploitation methodology
* Tools and commands used
* Privilege escalation where applicable
* Findings and exposed information
* Mitigation or remediation notes
* Key lessons learned

The goal is not simply to record the final answer, but to document **how I approached and solved the problem**.
